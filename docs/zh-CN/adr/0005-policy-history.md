# ADR 0005：不可变凭证策略历史

[English](../../adr/0005-policy-history.md) | **简体中文**

状态：已采纳

## 背景

调用记录已保存 `content_policy.revision`，但只保留最新策略时，无法查看旧请求当时的规则和范围。需要在不保存请求内容、不引入数据库的前提下保留历史配置。

## 决策

使用 schema 2 的单个 `policies.json` 同时保存当前策略和不可变历史。保存成功时原子追加版本并启用最后一项；写入失败时两者均不发布。保留版本冲突检查、私有权限、有界读取和启动校验。最多保留 1024 个快照或 8 MiB，达到上限则拒绝保存，不静默删除历史。请求审计和上游准入行为保持原有约束。

提供仅管理员可读的倒序游标分页和精确版本查询。请求追溯使用凭证检查版本，不能使用独立的连接／应用版本。新实例保留默认版本 0；旧 schema 1 文件不在加载时重写，以原有最新版本为历史起点，下一次保存成功后迁移。更早的缺失版本返回 404。

以后端 API 和测试为主要交付；复用现有调用详情提供最小只读查看入口，不新增历史管理页面。

## 影响

历史在重启后保留，并发检查使用一致快照。文件不包含提示词、回答或命中凭证。达到容量上限时保持原策略，但不能继续保存。旧程序无法读取 schema 2，迁移前需一致备份实例。这是配置历史，不是防篡改证据、管理员归因、历史模型授权、回滚引擎或法律合规证据。
