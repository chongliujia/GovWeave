# ADR 0007：产品登记与网关证据评估

[English](../../adr/0007-product-evidence-assessments.md) | **简体中文**

状态：已采纳

## 决策

在 ADR 0006 基础上增加有界、私有的产品登记。每个产品绑定应用 ID 和一个精确版本的规则包。明确持久化管理事实，保留 `runtime.*` 命名空间给网关适配器，区分管理员的证据声明与服务器观察到的配置和调用样本。

管理变更和网关操作完成后发送不阻塞请求的合并通知，并增加周期性的时钟检查。辅助评估不阻断推理，也不改变审计容量预留。发布前检查来源版本；来源变化或已知时间边界到达后，缓存失效。待评估／错误响应不携带旧的通过结果。

最新报告有界保存在内存，启动后重建；资料通过私有原子文件和版本冲突检查保存。不采集模型文本、凭证或任意请求头。调用样本是全局最新 100 个索引条目，不是完整历史，也不是每个产品独立的 100 条。

## 影响

产品可以基于当前网关证据自动重评。它是有界调度的持续辅助评估，不承诺延迟，不独立验证管理事实，不提供历史报告归档或法规驱动的执行。无状态评估 API 继续接受调用方事实。接口与边界见[产品持续评估](../product-assessments.md)。

后续 [ADR 0008](0008-regulatory-draft-report-snapshots.md) 增加显式报告持久化；自动最新状态仍保留在内存。
