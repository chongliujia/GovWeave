# ADR 0009：有界主动生命周期测试

[English](../../adr/0009-active-lifecycle-testing.md) | **简体中文**

状态：已接受

## 决策

增加版本化测试包、每产品一个修订计划、异步部署前测试与显式开启的运行期复测。通过进程内部管理员授权的应用身份，经网关执行，保留授权、撤销、凭证策略、传输限制和审计故障时停止上游的机制。不通过 HTTP 暴露此内部身份能力，合成流量独立标记。

测试包与规则包分离，只执行有界字面检查，不执行脚本、正则、LLM 裁判或推理重试。将保留的产品、网关事实及服务器拥有的测试事实交给现有规则引擎，未知不能变成通过。固定来源版本，仅比较相同配置。

模型调用前预留私有有界证据，重启时将未完成任务恢复为无法判断。助手正文须显式开启，在调用日志之外保存。重放只复算规则，不调用模型。NIST AI RMF 1.0 映射保持草稿、部分支持和人工复核状态，不宣称认证或全面满足框架。

## 影响

管理员可对配置端点主动测试并在运行期复测，无需新前端或运行依赖。启用计划可能产生提供者费用，限制见[主动测评](../active-assessments.md)。浏览器交互、语义检测、真实流量内容监测、相关方反馈、事件响应和上线审批仍独立建设。本决策扩展 ADR 0001 的初始网关优先范围。

## 扩展：同产品的两个目标计划

每产品现支持一个模型计划和一个读取工具计划，包含已有默认计划。命名计划显式指定 ID，独立维护修订／调度，共享每产品并发限额。产品报告合并两个独立事实命名空间；单次运行仍只针对自己的计划。旧默认计划及运行序列化保持兼容，见[同一产品的模型与工具测评](../application-assessments.md)。
