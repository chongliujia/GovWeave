# ADR 0008：有出处的法规草案与评估输入留存

[English](../../adr/0008-regulatory-draft-report-snapshots.md) | **简体中文**

状态：已采纳

## 决策

依据官方来源提供一个窄范围欧盟 AI 客服交互透明度映射，明确保持草稿与辅助评估状态。区分法律义务和辅助验证实践；人工判断不能自动批准，发现项区分技术缺口、证据缺口和人工行动。不从网关流量推断整个产品合规或实际界面行为。

新增管理员显式报告保存。独立保留产品资料、完整规则包、结构化事实、运行来源版本、引擎版本、评估时间、发现项及结果。使用私有有界文件和不可变 ID，API 不更新或静默裁剪历史；周期性重评仍只更新内存，不自动消耗归档容量。

重放使用保存的规则、输入和时间，不查询当前插件。引擎语义不支持时返回版本错误；支持的版本在读取时会复算，并与运行索引中的文件摘要校验。摘要不是签名或防篡改存储。显式保存会有意持久化治理事实值；适配器不采集模型文本或凭证。

## 影响

此功能提供可审核的法规示例和可复现历史报告，人工法律审核、外部证据验证和执行仍独立建设。初始上限为 256 个快照、每个 1 MiB、总计 64 MiB、8 个并发归档／重放操作。损坏的既有证据拒绝加载，不静默丢弃。范围、来源和接口见[欧盟草案与报告快照](../eu-transparency-reports.md)。
