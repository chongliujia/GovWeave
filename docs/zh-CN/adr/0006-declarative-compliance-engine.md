# ADR 0006：通用评估引擎与声明式规则包插件

[English](../../adr/0006-declarative-compliance-engine.md) | **简体中文**

状态：已采纳

## 背景

GovWeave 需要随法规变化持续评估 AI 产品。将某一法域写死在网关内，或将凭证检查当作整体产品合规，会限制这一目标。规则还需要模型流量本身无法证明的产品背景和证据。

## 决策

使用独立、确定性的 Go 评估器，启动时从实例 `rule-packs/` 目录加载 JSON 包。包标明框架类型、来源、版本、审核元数据、生效时间、适用条件和控制项。通过有界表达式和类型化证据计算，不执行插件代码、不访问来源链接。评估绑定精确 ID／版本与内容摘要。

使用三值逻辑和明确的逐项适用性判断，缺失或不可用证据保持未知。输出技术结果和证据引用，不返回事实值，不输出整体法律合规结论。审核元数据只是维护者声明，不等于验证过的审批；首版全部规则包都只提供辅助评估。

提供仅管理员可访问的规则包目录和无状态评估 API，不新增管理页面。产品持久化、可信证据适配器、事件触发重评、报告保存和执行映射分阶段建设。现有凭证策略继续独立执行。

## 影响

在现有表达式和证据足够时，可安装新包及新版本，无需重新编译。新的法律概念或测量要求可能需要补充适配器或引擎能力。无效包阻止启动。运维需外部保留规则包、输入和结果以便复现；摘要不提供签名或历史归档。附带包是虚构内部策略草稿，不提供法规覆盖。
