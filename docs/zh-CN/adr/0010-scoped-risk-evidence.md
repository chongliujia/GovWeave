# ADR 0010：显式限定范围的风险证据

[English](../../adr/0010-scoped-risk-evidence.md) | **简体中文**

状态：已接受

## 决策

以独立、可选的证据保险库，支持显式配置、限定应用范围的调查正文证据。运营者配置启用的是功能，不代表已经建立收集正文的法律依据。它只在该保险库内扩展初始“不保存正文”的边界；普通调用记录、诊断日志、追踪视图及报告运行证据引用继续只含元数据。

捕获默认关闭。metadata 和 full 两种模式都要求明确选择已存在的应用 ID。为已准入请求冻结捕获配置，保留有界输入、准备的上游输入、观察到的上游输出、准备的客户端输出及可用策略快照。保留缺口和交付不确定性。使用独立 AES-256-GCM 密钥、私有文件、不可变认证证据包及有界留存和容量。

该存储补充已有持久化调用审计。捕获失败不改变已准入推理结果，也不绕过审计或策略关卡；成功留存前不宣称证据存在。原文和有限模式预览都需要管理员会话、显式视图／原因及已提交的元数据访问事件，之后才释放内容。预览不代表匿名化。

单份证据图只根据同一应用的留存元数据建图，最多 32 份捕获。调用方声明的追踪关系始终是声明，不推断数据流或任务完整性。独立地把精确的应用范围最近 100 条全局审计样本，以及每个事实的请求引用，冻结到新产品报告及其显式归档中；正文保险库关闭时也可用。

## 影响

运营者可以调查某次已捕获决策的观察输入、原始输出、准备输出和策略依据。完整捕获可能保留敏感或已阻断文本，增加存储、访问控制与备份责任。到期后拒绝访问并支持有界删除，不擦除外部副本，也不保证物理安全擦除。本机密钥不是远程 KMS 或外部认证。缺少外部／只写一次的校验锚点及认证清单时，重启前整包删除或截去访问日志的有效尾部仍可能无法发现；这不是完整防篡改的取证链。证据缺失和图不完整保持未知；不生成校准风险概率或法律结论。接口和已实现限制见[留存风险证据](../risk-evidence.md)。

## 扩展：有界 SSE 阶段证据

流式输出可以分别保留已校验的完整帧和纳入下游写入尝试的完整帧，并附加可选 `sse-evidence-v1` 清单。保留字节总数、应用范围 HMAC、结束状态和前 128 帧观察。完整捕获在当次冻结对象上限内保留整个已观察阶段，否则省略整个正文；不完整流始终明确标为不完整。终态审计之后只捕获一次，不逐帧捕获，因此进程突然终止可能丢失进行中的证据。流时间是受批处理影响的网关观察时间，不是 token 耗时；写入计数不证明客户端收到内容。这不新增流式输出保护，也不提供重建文本后的脱敏。

## 扩展：显式限定范围的任务证据

管理员可以明确选择 1–16 个应用，使用独立的任务元数据视图。最多读取 32 份认证证据，与近期审计观察合并为最多 128 次调用；分别报告各数据源上限，区分未找到、不可用和超出读取预算的证据。发现只来自成功读取的证据。调用方声明的父子、汇合和重试引用只在返回的调用中解析；重复 span 保持歧义。应用密钥仍限于自身应用。视图是实时、非原子的合并结果，不是报告归档，也不证明数据流。正文访问继续要求独立授权和先写访问日志。

## 扩展：历史任务快照

只有服务端重新计算的摘要与页面所见视图一致时，才显式归档任务视图。冻结元数据和覆盖状态，不复制正文或完整保险库策略／对象文档。列表、读取和导出均要求完全相同的应用集合。私有元数据通过绑定证据密钥、独立用途派生的本机 HMAC 认证；限制数量、字节和并发，不自动驱逐。导出和历史读取只使用已认证的保存元数据，不重新读取实时调用，也不调用模型。历史可用性不代表当前可用性，正文到期不会删除元数据快照。JSON 下载附带精确字节的摘要，确定性 Markdown 报告引用该 JSON 摘要。本机认证和校验值不证明完整性、可信时间、实际因果或法律合规。
