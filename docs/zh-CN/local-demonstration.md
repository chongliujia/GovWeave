# 本机测评演示

[English](../local-demonstration.md) | **简体中文**

没有真实 AI 应用，也能验证 GovWeave 的测评流程。本演示启动真实网关和一个独立、只监听回环地址的脚本模拟客服 API，在隔离临时实例中安装合成测试包与 NIST 生命周期草稿，并保留实际测评报告。只需 Python 标准库及已编译的 Go 程序，不需要提供者账号、模型下载、外部服务或客户数据。

## 一键运行

在源码仓库执行：

```bash
make demo
```

它会编译程序并依次运行四个阶段：

| 阶段 | 预期用例结果 |
| --- | --- |
| 正常状态，部署前基线 | 4 项通过 |
| 正常状态，运行期基线 | 4 项通过 |
| 故意出错 | 2 项通过、2 项失败，记录 2 项退化 |
| 修复状态 | 4 项通过，记录 2 项恢复 |

四个检查分别是：包含合成身份句子、不输出指定假诊断标记、返回精确拒绝标记、返回合法 JSON 语法。出错时，模拟 API 故意输出假诊断标记，并对他人账户请求返回接受标记；修复后恢复正常脚本回答。不会读取或修改真实账户。状态切换是在同一目标配置后注入变化，以演示结果比较，不代表软件独立发现了真实部署版本。

终端默认英文。编译后可使用中文版本：

```bash
python3 scripts/demo-assessment.py --lang zh-CN
```

## 手动切换状态

```bash
python3 scripts/demo-assessment.py --interactive --lang zh-CN
```

程序先记录部署前和运行期基线，再接受命令。例如：

```text
broken
run
fixed
run
unavailable
run
quit
```

`normal`、`broken`、`fixed`、`unavailable` 分别切换正常、故意出错、修复及不可用状态；`run` 执行运行期测评，`status` 查看状态，`quit` 退出。不可用状态返回合成 HTTP 错误，用例保持未知，当前运行期测试不会继续使用上次通过的结果。输入结束也会退出。

## 报告与运行边界

每次创建新的 `dist/assessment-demo/<唯一运行目录>/`。`summary.json` 列出场景状态、用例数量、退化与恢复；`run-01.json`、`run-02.json` 等保留实际 API 返回的测评记录，包括合成助手回答。可用 `--output-dir 新目录` 指定位置；已有目录会被拒绝且内容不变。报告权限为 `0600`，结果目录为 `0700`。

演示为合成数据明确开启回答留存，不导出管理员密码、应用密钥或上游凭证。管理员密码只在内存中随机生成，不配置提供者密钥。运行数据目录与 `./data` 及继承的实例配置隔离；退出或 Ctrl-C 时关闭本机服务并删除临时实例，导出的报告保留。执行失败返回非零状态码，已经完成的阶段文件仍可排查。

本演示**关闭周期调度**，通过明确请求执行运行期阶段。真正的周期工作器、持久化计划恢复及限额见[主动测评](active-assessments.md)，其验收测试覆盖重启后的自动运行期测评。本演示不接入或修改已有实例，需要本机端口权限；可用 `--binary /绝对路径/govweave` 指定候选程序。启动脚本属于源码仓库开发工具，不是 Go 服务运行依赖，也不随纯二进制包提供。

## 能验证什么

模拟客服 API 是确定性脚本，不是训练后的模型。本演示验证真实网关及规则引擎是否能执行请求、发现已知脚本缺口、留存报告并比较结果。一句身份说明、一个隐藏的假标记或拒绝标记不能证明普遍的告知充分性、隐私或授权效果；测试包也不是代表性风险基准。NIST 草稿仍保留人工复核项，报告保持 `legal_compliance: not_determined`。

编译后可验证启动工具：

```bash
python3 tests/demo-smoke.py
```

覆盖一键及交互使用、不可用时保持未知、报告权限、拒绝覆盖已有目录，以及模拟接口的畸形请求和大小限制，只使用本机服务。
