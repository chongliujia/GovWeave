## 当前实现

应用或 Agent 的模型客户端发送请求后，网关依次校验应用身份和模型授权、执行适用的本地凭证检查、持久化开始记录并预留结束容量，再根据策略决定阻断或访问模型。流式回答按事件转发，结束时记录结果。认证、输入校验、并发限额和记录故障也可提前停止请求。

控制台、策略检查与转发在同一个 Go 进程中运行。配置和元数据保存在本地私有文件，不依赖 PostgreSQL、外部策略引擎、云端控制面或遥测收集器。数据目录通过单实例进程锁保护，不支持多进程或多主机共享。模型可以是内网服务，也可以是配置的云端上游。

## 后续规划

MCP 执行控制、审批、更多检测器、完整历史策略快照和人工审核的 EU/US 法规映射仍属后续工作。此列表不构成交付日期或法律覆盖承诺。各功能的具体限制以对应指南为准。

文档中的回环地址用于本机测试，`.example` / `example.com` 域名只是占位符。企业需配置真实网络地址、证书和上游模型；GovWeave 不自动提供这些资源。
