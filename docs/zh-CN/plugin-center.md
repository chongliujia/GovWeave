# 插件中心

[English](../plugin-center.md) | **简体中文**

管理员登录后进入 **管理 → 插件中心**。页面仅列出实际安装的规则包和可执行的敏感文本检测器版本，不会把未安装框架显示为可用。支持中英文、离线运行，检测内容不传给外部服务。

## 选择与配置操作

- 用“检测器与脱敏”“合规框架与规则包”页签分别配置。切换页签或语言会保留两边的草稿；页签支持方向键及 Home/End。
- 检测器卡片直接对比版本覆盖范围，处理模式卡片说明效果。选中边框表示当前草稿，“已保存配置”标记表示已存储的版本或模式；只有保存才改变实际配置。
- 规则包可按名称、ID、版本搜索，并按框架类型筛选。筛选不会解除已有版本选择；完整元信息在“版本详情与指纹”中展开查看。
- 应用支持搜索、“选中筛选结果”和“清除筛选结果”。批量操作只作用于当前匹配项，不影响筛选外的选择；计数统计全部已选应用。
- 底部保存栏提示未保存修改、目标范围和缺失的必填项，编辑时保持可达。“放弃修改”只恢复当前表单，不影响另一页签的草稿。切换产品或重新加载前会确认是否放弃未保存修改。
- 公开邮箱例外、安全说明、版本历史和已保存产品评估按需展开。产品草稿保存或放弃后才能执行评估，避免把旧配置结果当作新配置结果。

## 选择合规框架／规则包

1. 将验证过的纯数据 JSON 规则包安装到 `<data_dir>/rule-packs/`，重启 GovWeave 后重新加载页面。格式要求见[规则包与评估](compliance-engine.md)；无效规则包会导致启动失败。保留历史报告依赖的旧版本。暂不支持网页上传、远程安装或热加载。
2. 选择已有产品，或者新建产品，填写名称、版本和关联应用。
3. 选择精确的已安装规则包版本，查看框架类型、审核状态、控制项数量及 SHA-256。“已审核”是发布方的元数据声明，不代表独立核验或认证；草案状态明确保留。
4. 保存后点击“评估已保存的产品”。未保存修改不参与评估；编辑产品保留已有事实，新建产品不预填声明证据，证据缺失仍是未知而非通过。

当前每个产品绑定**一个规则包版本**。不同产品可选择不同规则包，也可关联相同应用。切换规则包不会改变运行时策略或已归档报告。选择框架不代表满足法律合规要求；本界面不新增或认证 ISO、NIST、EU 等法规映射。

## 选择检测器／脱敏策略

内置 `sensitive-text` 插件提供三个显式版本：

| 版本 | 范围 |
| --- | --- |
| `sensitive-text-v1` | 原有有界凭证、邮箱和中国大陆手机号模式检测 |
| `sensitive-text-v2` | 增加有界全角、零宽字符和括号邮箱格式归一化 |
| `sensitive-text-v3` | 增加配对邮箱格式及有界单层 Base64 检测 |

选择**停用、观察、阻断或脱敏并复检**，勾选检测类别，并明确选择所有应用（含未来应用）或非空的指定应用范围。精确公开邮箱例外可按行填写，不豁免其他控制。只有保存后才生效；选择卡片本身不改变策略，也不会自动升级到最新版本。

通过“策略配置对象”选择“默认策略”或一个应用。每个应用可独立选择处理模式、检测器版本、类别及邮箱例外；独立策略替换该应用的默认设置。默认策略的范围只作用于没有独立配置的应用。“使用默认策略”移除独立绑定；应用历史中的“为此应用恢复”将历史生效设置复制为新的独立绑定。停用或切换会创建新修订，保留策略历史；不提供破坏性卸载和历史改写。并发保存会拒绝旧修订：保留想要的修改，重新加载最新配置，核对后再保存。

保护作用于受支持的非流式模型回答和工具输出。受保护的流式请求会被拒绝，不会默默绕过。受保护的检测不完整或失败时会扣留输出，包括观察模式；观察模式在检测完成后返回原文。独立内容检测接口只返回观察及处理建议，不替换文本。具体限制、例外、误报和漏报见[敏感输出保护](sensitive-output.md)。

## 保存前试测
欧美首批可选目录、证据字段和隔离测试见[欧美合规首批包](eu-us-compliance-bundle.md)。新增映射是数据插件，不增加法律审批能力，也不自动启用执行策略。


点击检测器卡片旁的“保存前试测”，加载合成邮箱、编码文本或凭证样例，也可输入自己的合成 UTF-8 文本。“试测当前草稿”使用当前选择的检测器、模式、类别和精确公开邮箱例外，不保存任何配置。试测假设文本在保护范围内，**不验证具体应用是否受到保护**。

结果显示命中的所选类别／规则、应用的例外、处理动作，以及可返回的文本。脱敏复用运行时转换和复检逻辑；凭证命中可能替换整段输出。阻断或启用保护后的不完整／失败检测不会返回文本。停用模式不扫描，直接返回样例。样例或草稿变化后旧结果立即失效。“清空样例与结果”和退出登录会从控制台移除样例及结果；切换语言保留样例，不翻译用户输入。

管理员专用 `POST /api/v1/plugins/sensitive-output/preview` 接收 `text`、`detector_version`、`mode`、`categories` 和可选 `public_emails`。沿用控制台来源及自定义请求头检查、严格 JSON 解析；JSON 请求上限为 16 KiB，解码后的文本上限为 8192 字节。不接受策略修订或应用范围字段，避免误认为是已保存或已路由的评估。响应标记 `preview_only: true`，使用 `Cache-Control: no-store`；扣留时不返回 `output`。

样例仅发送至当前 GovWeave 实例，不调用模型或上游服务。GovWeave 不持久化样例或响应，不修改策略及历史，也不生成调用／证据记录。GovWeave 之外的基础设施可能有自己的日志策略，因此请使用合成数据。该功能仅辅助纯文本配置，不是合规证据、完整检测保证，也不覆盖模型响应封装、工具参数保护和应用路由。

## 规则包详情与逐项结果

在“合规框架与规则包”页签展开“规则包覆盖范围与来源”，查看所选已安装版本的定义：声明覆盖范围、排除项、来源版本／核对日期、发布方审核元数据、生效时间、指纹及逐项控制定义。每项可查看引用条目、严重性、评估方法、依据、声明整改建议及原始适用条件／要求表达式。来源链接仅在点击后打开；规则包内容按文本渲染，不执行 HTML。未提供的范围、限制或日期会明确标注，不补造，也不视为完整覆盖。

展开“已保存产品的评估”，点击“读取最近评估”读取已有结果，或“评估已保存的产品”刷新评估。面板标明产品修订／版本、固定规则包版本／指纹、引擎版本、评估／刷新时间及运行时采样上限。统计以全部返回控制项为分母，分别显示满足技术要求、控制缺口、证据不足／待审核及不适用，不推导认证分数。

可按状态、“需要处理”或“待人工审核”筛选，也可搜索 ID、标题、引用条目及证据事实名称。展开控制项后，查看判定原因、证据缺失／时效／过期／来源／类型问题、记录的下一步建议，以及证据 ID、来源、观测及过期时间。操作者声明不是独立核验证据；人工要求仍保持未知，直到独立的合格审核流程完成。此面板不编辑证据，也不提供审批按钮。

结果是评估快照，而非实时结论。修改或切换产品、切换所选规则包、重新加载配置或保存检测器策略，都会隐藏旧结果。产品 ID／修订／版本及规则包 ID／版本／指纹匹配后，才展示就绪结果。待处理、失败或版本不匹配时，不复用旧的通过结果。快照超过返回的刷新期限会明确提示；其他位置的配置变化仍需重新读取评估。迟到的规则包响应不会覆盖新选择。不增加法律映射，也不默认安装规则包。

## 插件实现与接口

- 管理员专用 `GET /api/v1/plugins` 返回实际安装的 `rule_packs` 和敏感检测注册表中的 `detectors`，包括版本、类别、模式及输入边界。
- 产品选择复用已有带修订检查的 `/api/v1/compliance/products` 接口；评估使用已保存产品的 `/evaluate` 接口。
- 检测器配置复用 `/api/v1/policies/sensitive-output`；`/history` 返回不可变策略修订。沿用现有鉴权、来源检查、校验、持久化和运行时证据。
- 规则包是数据插件；检测器是可信、随 Go 程序编译的实现。在 `internal/sensitive/plugins.go` 注册并测试新检测器，再明确重建部署。目录、支持版本检查和运行时 `Scan` 共用注册表；冻结的 v1/v2 历史入口不变。不支持上传任意代码或动态加载 `.so`。
- `internal/detection` 的离线标记检测实验仍独立，不会被当作生产脱敏器展示。

## 验证

准备好 Go、Node、Playwright 和 Chrome 后：

```sh
make build
make check
go test -race ./...
node tests/plugins-smoke.cjs
```

浏览器验收使用隔离数据、两个合成规则包版本、两个应用和本机模型，检查草稿试测、脱敏复检、不完整检测扣留、安全文本渲染、旧结果失效、试测隔离及退出清理。同时覆盖规则包选择、事实保留、实际按范围脱敏、中英文草稿保留、策略历史、并发冲突、缺失规则包、加载失败与重试、重启持久化及响应式布局。不调用外部模型，不修改正在运行的生产实例。可用 `GOVWEAVE_TEST_BINARY` 和 `GOVWEAVE_BROWSER_PATH` 指定测试二进制和浏览器。
