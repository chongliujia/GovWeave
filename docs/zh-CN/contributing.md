# GovWeave 贡献者与编码 Agent 指南

此指南描述当前仓库。[早期中文草案](archive/initial-design.md)只保留设计历史，其 Eval 优先和假设已有 GRC 产品的前提已被[架构决策](README.md#架构决策)替代。

## 当前范围

实现企业自部署的模型接入、受控只读工具、本地请求凭证检查、可选敏感输出保护、检索指令检查与元数据调用记录网关。共享检测器、独立检测 API、策略历史与冻结测量边界见[敏感输出保护](sensitive-output.md)。当前是单个 Go 进程、内嵌 HTML/CSS/JavaScript 和私有文件存储；没有已有 GRC 后端、Python 服务、独立 GovWeave SDK、MCP 执行器或法规执行目录。

以[项目首页](../../README.zh-CN.md)、[开发文档](development.md)、[OpenAPI](../../api/openapi.yaml)和已采纳 ADR 为准。计划能力应明确标记为尚未实现。

[异构 Agent 追踪](agent-tracing.md)为网关调用增加显式、有界关联。应用范围经过鉴权，Agent 标签与调用关系仍是调用方声明；追踪必须保留应用隔离、仅存元数据和历史不完整提示。

[风险证据](risk-evidence.md)单独支持显式指定应用范围的加密正文留存。区分原始输出与准备返回的输出，保留采集和检测器版本，在释放正文前记录特权访问；不得将保险库正文复制到普通调用日志、图谱、报告或诊断中。正文采集是补充证据，无法取得时必须保持未知；应用声明的关系和相同内容指纹不是独立的因果证明。

## 工作原则

- 优先完成可用的端到端行为，再扩展范围；保持 Schema、实现、控制台、示例和文档一致。
- 区分管理员身份、应用密钥和上游凭证。模型授权与凭证策略范围不能混为一谈。
- 不在调用记录中保存秘密、提示词、回答、任意调用头或上游原始错误；不提交真实实例数据和凭证。
- 请求与授权阻断必须在上游 I/O 前执行；输出保护必须在向调用方释放文本前完成检查及持久化决定。保留记录容量预留和日志不可用时停止上游的行为，不静默丢弃记录。
- 限制输入、输出、并发和存储容量。使用代表性负载测量性能，区分检测器耗时与端到端时延。
- 使用版本化、不可变的策略快照。技术检查或访问授权不是法律结论；未来法规解释和强制控制映射需要来源依据与人工审核。
- 保留离线运行和内嵌资源。新增依赖须有足以承担安装和维护成本的价值。
- 控制台和文档默认英文，提供简体中文。不要翻译用户填写的名称、别名、标识符、URL 或秘密。
- 验证改动行为及有意义的失败场景，如实报告范围和局限；合成测试不是生产证据。
