# 本机试用 GovWeave

[English](../try-it.md) | **简体中文**

用真实网关和本机脚本模型，验证普通回答放行、合成邮箱脱敏，以及含合成凭证的输入在访问模型前被拦截。无需提供者账号、API Key 或模型下载。

[观看 60 秒分步演示](short-demo.md) · [接入自己的应用](application-onboarding.md)

## 运行三个场景

使用 Linux、macOS 或 WSL，准备 **Git、Make、Go 1.24+ 和 Python 3.10+**，并允许本机回环端口监听。请使用受支持且包含安全更新的 Go 版本；分发构建固定为 1.26.9。这条路径从源码运行，不适用于仅含二进制的分发包。无需 Node 或浏览器依赖。

```bash
git clone https://github.com/chongliujia/GovWeave.git
cd GovWeave
make demo-quickstart DEMO_LANG=zh-CN
```

如果已有当前仓库，只需在仓库根目录执行最后一条命令。克隆仓库或获取 Go 工具链可能需要联网；试用本身只使用本机服务和 Python／Go 标准库。首次编译可能比后续运行更久。

编译完成后的预期结果：

```text
1/3 普通回答：HTTP 200，原样返回。
2/3 合成邮箱：HTTP 200，返回 Synthetic email: [REDACTED]。
3/3 输入含合成凭证：HTTP 403，在访问上游前阻断。
已核对 3 条终态审计及关联证据；本机模型收到 2 次请求。
临时网关、凭证和正文证据已清理。
```

命令自动结束，不会留下持续运行的控制台。退出码 0 表示这三项检查通过；检查失败返回 1，中断返回 130。最后打印的摘要路径每次不同。

## 试用实际验证了什么

| 场景 | 验证内容 |
| --- | --- |
| 普通回答 | 原样返回指定合成回答，HTTP 200，留下终态审计 |
| 模型输出包含邮箱 | `demo.person@example.com` 被替换为 `[REDACTED]`，HTTP 200，记录检测器和策略修订 |
| 输入包含凭证 | HTTP 403、`policy_blocked`、输入策略命中，且没有访问上游 |

脚本创建全新的应用凭证，为该应用配置输入阻断和输出脱敏，并且**仅在临时实例中**显式开启完整证据采集。正常网关默认值不变。脚本核对三条证据，检查普通审计不包含合成正文和凭证，退出时清理临时实例、加密正文和凭证。已有 `./data`、环境变量指定的 GovWeave 实例及 Docker 数据卷均不参与试用。

仅保留 `dist/quickstart/<唯一运行目录>/summary.json` 元数据摘要，目录权限 `0700`、文件 `0600`。摘要包含请求 ID、HTTP 状态、策略修订和检查结果，不包含应用密钥或请求／响应正文。此目录已被 Git 忽略。

本机模型返回固定文本。这三个非流式场景验证接入与控制流程，不衡量真实模型安全、检测召回率、流式拦截、生产性能或法律合规性。

## 下一步：接入自己的模型

按[应用接入指南](application-onboarding.md)启动持久实例、配置模型连接、创建应用密钥，再用网关 BASE URL 和模型别名发送一次请求。适用策略需要显式配置；选择规则包不会自动开启运行时保护。

## 命令没有成功时

| 现象 | 处理方法 |
| --- | --- |
| 找不到 `go`、`make` 或 `python3` | 安装前提工具并检查版本；Windows 请在 WSL 中执行这些命令。 |
| 无法启动本机服务 | 为试用允许回环端口监听。端口自动选择，不要求占用 8080。 |
| 某项检查失败 | 保留终端输出，确认编译的是当前仓库；失败不能解释为保护成功。 |
| 希望使用英文输出 | 执行 `make demo-quickstart`。 |
| 已经编译网关 | 执行 `python3 scripts/demo-quickstart.py --lang zh-CN`；可用 `--binary /绝对路径/govweave` 指定其他构建。 |

源码见 [scripts/demo-quickstart.py](../../scripts/demo-quickstart.py)。可选的分步演示截图生成方式见[演示素材指南](short-demo.md#更新演示素材)。
