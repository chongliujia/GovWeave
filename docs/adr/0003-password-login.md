# ADR 0003：本地管理员密码与浏览器会话

- 状态：已采纳，2026-10-15
- 依据：用户明确要求直接设置初始登录密码，去掉令牌操作。

## 决定

首次打开控制台设置并确认密码，完成后自动登录；以后输入密码。无需云端账号、用户名、默认密码或手动复制管理凭证。登录后刷新页面保留会话，退出在服务端撤销；会话 8 小时失效，进程重启也会清空。单管理员范围不变，应用 API Key 保持独立。

密码使用随机 16 字节盐、PBKDF2-HMAC-SHA256（600,000 次迭代），只保存哈希及参数到权限 0600 的 `admin.password.json`。使用 [Go 标准库 PBKDF2](https://pkg.go.dev/crypto/pbkdf2)，避免自写密码派生算法和增加联网依赖；Go 最低版本因此从 1.22 提升到 1.24，分发工具链仍固定 1.26.9。参数参考 [OWASP Password Storage](https://cheatsheetseries.owasp.org/cheatsheets/Password_Storage_Cheat_Sheet.html) 的 PBKDF2-HMAC-SHA256 配置；不据此宣称 FIPS 认证。哈希工作仅发生在初始化和登录，不进入模型调用路径。

会话值使用密码学安全随机数生成，服务器仅在内存保留其哈希与到期时间，最多 128 个会话；浏览器使用 HttpOnly、SameSite=Strict Cookie，路径限定 `/api/`，HTTPS 带 Secure。管理写操作要求 JSON、自定义请求头和 Origin 校验；不启用 CORS、不信任转发头确定客户端身份。密码尝试全实例每分钟最多 10 次，派生计算并发为 1；这是单管理员预览版的简单限制，不是分布式防爆破系统。

## 初始化与兼容

新实例应在受控网络中完成首次设置后再开放。已有密码文件时，不允许再次初始化；损坏文件导致启动失败，不回退成无密码实例。

旧令牌文件只用于识别迁移，不能再访问管理接口。已有令牌而没有密码的实例只接受直接回环访问进行设置，避免更新软件就意外开放远程接管；容器或代理场景由部署管理员在隔离入口后迁移，步骤见 [部署文档](../deployment.md)。模型、应用密钥、实例配置和调用记录无需迁移。

不提供公共重置接口；遗忘密码由掌握数据目录的运维停机恢复。多管理员、MFA、SSO 和密码管理页面留待后续。
